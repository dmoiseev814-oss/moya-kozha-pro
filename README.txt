МОЯ КОЖА PRO — PWA-версия 1.3 для GitHub Pages
=======================================

СОДЕРЖИМОЕ
manifest.webmanifest — настройки установки PWA
sw.js — офлайн-кэш и обновление
icons/icon-192.png и icons/icon-512.png — реальные PNG-иконки
index.html  — пять экранов приложения
styles.css  — оформление и адаптивные стили
app.js      — логика, анкета, ритуалы, дневник и localStorage
README.txt  — инструкция

КАК ОТКРЫТЬ
1. Распакуйте ZIP в отдельную папку, сохранив четыре файла вместе.
2. Откройте index.html двойным щелчком в современном браузере.
3. Для стабильной работы локального хранилища рекомендуется открывать приложение
   через HTTPS на собственном статическом хостинге (публикация в этой версии
   не выполнялась). При открытии файла по file:// поддержка localStorage
   зависит от браузера. Не переносите записи между браузерами автоматически.
4. Все пути относительные: ./styles.css и ./app.js.

ВОЗМОЖНОСТИ
- Главная страница и навигация по пяти разделам.
- Анкета: семь вопросов, один за экран, прогресс, назад/далее, повторное прохождение.
- Четыре варианта общих сценариев: «Нежность и комфорт», «Красота простоты»,
  «Забота и защита», «Ритм заботы».
- Утренний и вечерний ритуалы с отдельными галочками для текущего дня.
- Дневник за последние 30 календарных дней: ощущения, заметка до 500 символов,
  отметка дней с записями и шкала прогресса.
- Темы «Розовый кварц» и «Шампань».
- Экспорт данных в JSON, импорт сохранённого JSON с проверкой формата и
  подтверждением замены, удаление данных после подтверждения.

ПРИВАТНОСТЬ
Сведения хранятся в localStorage данного браузера. Нет регистрации,
сетевых запросов, внешних шрифтов, библиотек или ИИ API.
Очистка данных браузера или приватный режим могут удалить записи.
Экспорт JSON предназначен для резервной копии; для восстановления нажмите
«Импорт данных JSON» и выберите экспортированный файл (до 2 МБ).
Импорт заменяет текущие данные только после подтверждения.
Сохраняйте резервную копию в доступном вам месте, не передавайте третьим лицам.

ВАЖНО
Приложение посвящено привычкам базового ухода. Оно не определяет тип кожи,
не ставит диагнозы и не заменяет консультацию дерматолога. При стойких
неприятных ощущениях обратитесь к специалисту.

КАК ПРОВЕРИТЬ ВРУЧНУЮ
1. Откройте index.html: должна появиться главная.
2. Переключите обе темы, затем перезагрузите страницу.
3. Пройдите семь вопросов; проверьте «Назад», прогресс и итоговую карточку.
4. Перепройдите анкету; проверьте изменение карточки.
5. Отметьте утром и вечером шаги; обновите страницу и проверьте галочки.
6. В дневнике выберите день, сохраните ощущение и заметку, обновите страницу;
   проверьте календарь и прогресс за 30 дней.
7. Экспортируйте JSON, затем удалите данные с подтверждением; убедитесь,
   что они сбросились. Импортируйте JSON, подтвердите замену и обновите
   страницу — проверьте восстановление анкеты, ритуалов, заметки и темы.

ЕЩЁ НЕ ВХОДИТ В ВЕРСИЮ 1.2
PWA, Service Worker, манифест установки, Android APK и публикация на GitHub Pages.
Без Service Worker гарантированная работа после публикации без интернета
пока не предусмотрена. Офлайн-работа локально открытого HTML зависит от браузера.


PWA — УСТАНОВКА И РАБОТА БЕЗ ИНТЕРНЕТА (ВЕРСИЯ 1.3)
===================================================
1. Сохраните структуру проекта неизменной; загрузите все семь файлов на GitHub
   Pages в подпапку репозитория moya-kozha-pro (публикация здесь НЕ выполнялась).
   Адрес проекта: https://ИМЯ.github.io/moya-kozha-pro/
2. Откройте сайт по HTTPS с интернетом, подождите загрузки обязательных файлов.
   Кэширование возможно только при успешном ответе сервера на ВСЕ файлы.
3. Android: в Chrome выберите «Установить приложение» или «Добавить на главный экран».
   iPhone/iPad: Safari → «Поделиться» → «На экран Домой».
4. Откройте приложение с иконки, затем включите авиарежим и повторно откройте.
   Убедитесь, что все пять разделов доступны, а сохранённые записи на месте.
5. Проверьте сохранение заметки, галочек и темы после закрытия/открытия офлайн.
   Для импорта/экспорта JSON используются только локальные файлы устройства.
6. Офлайн работает лишь после успешной первой загрузки онлайн и установки SW.
   Без HTTPS (кроме localhost) Service Worker не запускается. При file:// PWA
   не устанавливается. Мобильные браузеры могут очищать локальные данные.
7. Для обновления сайта измените CACHE_NAME в sw.js, например на
   moya-kozha-pro-shell-v1.3.1, опубликуйте все файлы и обновите сайт онлайн.
   После активации нового SW старые версии кэша удаляются. Текущие открытые
   вкладки иногда требуют перезапуска; не удаляйте данные сайта.
8. Ключ localStorage 'moya-kozha-pro-v1' и исходный app.js не менялись. Данные
   останутся на том же origin и пути хранения браузера. При переходе с file://
   на HTTPS данные обычно НЕ переезжают автоматически: сначала экспортируйте JSON
   из прежней версии, затем импортируйте его в PWA по HTTPS.
9. Иконки внутри ZIP — настоящие PNG размером 192x192 и 512x512, их можно
   заменить своими PNG тех же размеров, после чего обновить версию кэша.
10. Никаких запросов к сторонним API/сервисам. Сайт загружается с GitHub Pages,
    а локальные заметки не передаются на сервер. Проверка офлайн на телефоне
    остается обязательной и в этой сборке НЕ выполнена.
